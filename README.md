# Azure Startpaket

Filerna här är startpunkten för labbarna i kursens Azure-del. Kopiera dem till ditt eget kursrepo och bygg vidare därifrån.

En mapp per vecka:

- `v37-startpaket`, VM med cloud-init, nginx och en liten Python-app
- `v38-startpaket`, IaC med ARM-templates och Bicep

Varje veckomapp har en egen README med instruktioner.

Färdiga lösningar ingår inte.
